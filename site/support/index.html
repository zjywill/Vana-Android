Vana Android 支持

Vana 没有账号，也没有订阅。模型请求直接发送给你在设置里选择的 Provider。

第一次使用

  1. 打开“设置 › 云端模型”。
  2. 选择与你的 API 密钥对应的 Provider 和模型。
  3. 粘贴 API 密钥，点“测试连接”。
  4. 看到“连接正常”后返回聊天。

常见问题

提示 API 密钥没通过验证：确认密钥没有过期，并且 Provider 没选错。

提示额度用完：到对应 Provider 的账户页面检查余额或限额。

照片是否会上传：文字识别在设备上完成。原图默认不上传，发送前可以逐张决定。

换手机后数据没有恢复：对话、记忆、用药表和附件被排除在系统备份与设备迁移之外。

删除数据

可以分别删除对话、记忆、用药条目和家庭成员。卸载 Vana 会删除应用私有目录里的全部数据。
